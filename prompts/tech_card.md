# 기술 카드 작성 템플릿 (7블록)

본문 섹션 내 독립 카드. 특정 기술 하나를 개괄 + 핵심 특성으로 설명.

## 분량 기준 (중요도별)
- **high**: 2,500~3,500자
- **medium**: 1,500~2,500자 (기본)
- **low**: 800~1,500자

상한: 3,500자. 그 이상 상세 서술이 필요하면 **별첨 심층분석**으로 분리.

## 7블록 구조

### ① 기술 개요·배경 (300자)
- 등장 배경, 해결하려는 문제
- 기존 접근의 한계, 본 기술이 제시하는 돌파구
- 최초 제안자·시점 (알려진 경우)

### ② 작동 원리 (600~800자, 핵심)
- 알고리즘·프로토콜을 단계별 서술
- 핵심 아이디어를 한 문장으로 요약 후 세분화
- 수식·의사코드는 별첨에 양보, 카드는 **개념** 수준

### ③ 구성 요소 (HW/SW, 300~400자)
- 하드웨어 구성 (센서·액추에이터·통신 모듈)
- 소프트웨어 구성 (펌웨어·플랫폼·API)
- 요소 간 상호작용 요약
- 표 활용 권장 (요소명·역할·사양 3열)

### ④ 성능 지표 (300~400자)
- 정량 수치 (정확도·효율·속도·전력·비용)
- 측정 조건 (실험실·현장·규모)
- 기존 방식·경쟁 기술 대비 수치 비교
- `stat-highlight` 컴포넌트 활용

### ⑤ 기술적 장단점 (300~400자)
- 장점 3~5개 (각 1~2문장)
- 단점·제약 3~5개
- 구체적 근거 제시 ("~한 환경에서는 ~한 이유로 ~한 제약")

### ⑥ 차별점·한계·발전방향 (300~400자)
- 타 기술 대비 차별적 우위
- 이론적·실용적 한계
- 향후 발전 방향 (1~2문장)

### ⑦ 근거·인용 (200자)
- 3~5건 [REF-xxx] 핵심 출처 명시
- 각 REF의 핵심 기여 1줄씩

## 자체 검증
- [ ] 모든 블록 채움 (빈 블록 없음)
- [ ] [REF-xxx] 인용 5건 이상
- [ ] AI 추정 표현 < 30%
- [ ] 최소 분량 (중요도별) 충족

## 출력 형식
JSON with keys: `id`, `name`, `name_en`, `importance`, `overview`, `principle`, `components`, `performance`, `pros_cons`, `differentiation`, `references`, `ref_ids`.

각 블록은 HTML fragment (h4·p·ul·table 사용 가능).
