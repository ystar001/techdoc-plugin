# 표기 일관성 규칙 (Terminology, 한국어·영어 혼용 7항)

writer가 카드·별첨을 작성할 때 **처음부터 지켜야 하는 표기 표준**. 사후 교정(`edit_rules.md`)·검토(`review_consistency.md`)·측정(`check_quality.py`)이 모두 본 7항을 기준으로 한다. 약어 풀이 정책은 `abbreviation_rules.md`, 참고문헌 양식은 `reference_format.md`를 함께 참조한다.

표준 용어는 `outline.glossary`에 정의되며, `extract_glossary`가 KeyRef·카드에서 자동 추출해 채운다. glossary에 정의된 표준형이 있으면 그것을 우선한다.

---

## 1. 학술용어 — 한글 우선 + 첫 등장 영문 병기

- 한글 표기가 가능한 용어는 **한글 우선**.
- 카드 내 첫 등장 시 `한글(English)` 또는 `한글(English, ABBR)` 병기. 이후 한글 또는 약어 단독.
- 한글 단독으로 의미가 통하는 일반 표현(원격탐사·정밀농업)은 영문 병기 생략 가능.
- 한국어로 정착하지 않은 표현은 영문 단독 허용(`sim-to-real`, `domain shift`).

| | 예 |
|---|---|
| 올바름 | `정밀 관개(precision irrigation)는 토양 수분 센서로 급수량을 조절한다. … 이후 정밀 관개 단독.` |
| 잘못됨 | `precision irrigation은 … (한글 병기 없이 영문 단독)` |

## 2. 약어 — 첫 등장 풀이 후 약어 사용

- 카드 내 첫 등장 시 `정식명(ABBR)` 풀이 의무. 이후 약어 단독.
- 정착 약어 50선(`abbreviation_rules.md §정착 약어`)은 풀이 생략 가능.
- 같은 약어는 카드 내 1표기로 고정(`standard_form`).
- 상세 정책은 `abbreviation_rules.md` 참조.

| | 예 |
|---|---|
| 올바름 | `사물인터넷(IoT) 기반 센서망. … 이후 IoT 단독.` |
| 잘못됨 | `IoT 기반 센서망. (첫 등장인데 풀이 없음)` |

## 3. 기관명 — 한글 정식명 + 영문 약어, 1형태 고정

- 첫 등장 시 `한글 정식명(영문약어)`. 이후 약어 또는 한글 단독.
- 외국 기관은 `원어명(분류·국적 부연)`.
- 프로젝트 전체에서 **한 기관 = 한 표기**로 고정. `미국 농무부`/`美 농무부`/`USDA Dept.` 혼용 금지.

| | 예 |
|---|---|
| 올바름 | `미국 농무부(USDA)가 발표했다. … 이후 USDA.` / `Lindsay Corporation(미국 농기계 기업)` |
| 잘못됨 | `USDA가 … 그리고 미국 농무성이 … (같은 기관 2표기 혼용)` |

## 4. 제품명 — 원어 표기 보존 (고유명사)

- 제품·서비스명은 **영문 원어 유지**. 한글 강제 번역 금지.
- 첫 등장 시 제조사·분류 부연 권장.

| | 예 |
|---|---|
| 올바름 | `Netafim NetBeat(이스라엘, 통합 디지털팜 플랫폼)`, `John Deere Operations Center` |
| 잘못됨 | `네타핌 넷비트`, `존디어 운영센터 (제품 고유명 한글 번역)` |

## 5. 외래어 — 국립국어원 외래어 표기법

- 국립국어원 외래어 표기법을 기준으로 흔한 변형을 표준화한다.
- `데이터`(✓) / `데이타`(✗) · `알고리즘`(✓) / `알고리듬`(✗) · `프레임워크`(✓) / `framework 단독`(✗).
- 영문 slug는 한국어화: `framework → 프레임워크` · `baseline → 기준선` · `roadmap → 로드맵` · `pipeline → 파이프라인`.
- 단, 고유명사·제품명·기술 용어는 영문 보존(`attention mechanism`, `Foundation Model`).

| | 예 |
|---|---|
| 올바름 | `데이터 파이프라인을 구성한다.` |
| 잘못됨 | `데이타 pipeline을 구성한다.` |

## 6. 단위 — SI 단위·기호 일관

- 단위·기호는 영문 그대로: `km` · `ha` · `°C` · `%` · `GHz` · `kg/ha` · `m²`.
- 백분율·온도 등은 숫자와 단위 사이 **공백 없음**: `94.3%`(✓) / `94.3 %`(✗), `25°C`(✓).
- 통화: `1,200만 원` · `USD 5,000`. 정량 환산 일관: `1ha = 10,000m²`.

| | 예 |
|---|---|
| 올바름 | `정확도 94.3%, 평균 기온 25°C, 면적 95ha` |
| 잘못됨 | `정확도 94.3 퍼센트, 평균 기온 25도씨, 면적 95 헥타르` |

## 7. 표현부호 — 가운뎃점·붙임표·범위 일관

- 병렬 나열은 가운뎃점(`·`): `목적·방법·결과`.
- 범위는 물결표(`~`): `2,500~3,500자`, `2023~2025년`.
- 붙임표(하이픈)는 복합 고유명사·기간 표기 일관: `LoRa-Mesh`, `2023.01-2025.12`.
- 한 문서 내에서 같은 의미의 부호를 섞지 말 것(`~`와 `-`를 범위에 혼용 금지).

| | 예 |
|---|---|
| 올바름 | `목적·방법·결과를 2,500~3,500자로 서술한다.` |
| 잘못됨 | `목적, 방법, 결과를 2,500-3,500자로 서술한다. (가운뎃점·물결표 미적용)` |
