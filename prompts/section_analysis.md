# 섹션 종합 분석 블록 템플릿

각 섹션의 마지막에 배치되는 **종합 분석 블록**. 섹션 내 기술·프로젝트·제품 카드를 비교·통합해 **시사점**을 도출.

## 분량 기준
800~1,200자 + 시각화 컴포넌트 최소 1종

## 4개 구성 요소

### ① 비교 매트릭스 (comparison-matrix)
- 섹션 내 기술·제품 N개 × 5~7개 평가 축
- 축 예시: 정확도, 비용, 전력, 통신 범위, 유지보수, 확장성, 성숙도
- 각 셀은 정량값 또는 정성 등급 (상/중/하)
- 매트릭스 아래 1~2문장 해석

### ② 타임라인 (timeline)
- 섹션 내 주요 프로젝트·제품의 연대기
- 주요 마일스톤 (발표·상용화·대규모 도입)
- 분기점·변곡점 표시
- `<timeline>` 컴포넌트 활용

### ③ 성능·비교 차트 (matplotlib)
- 적절한 차트 유형 선택: bar(비교), line(시계열), radar(다차원), pie(구성)
- ChartGenerator가 받을 수 있는 `{id, type, title, data}` 명세 JSON 생성
- `stat-highlight` 등 주요 수치 부각

### ④ 섹션 요약 (section-summary, 300자 내외)
- 섹션 핵심 메시지 3~5개 포인트
- 공통 추세 (어떤 방향으로 흘러가는가)
- 경쟁 구도 (누가 앞섰고 뒤졌는가)
- 성숙도 (시장 진입기·성장기·성숙기)

## 작성 순서
1. 섹션 내 카드들을 읽고 공통 요소 추출
2. 비교 축 5~7개 결정
3. 매트릭스 표 작성
4. 타임라인 주요 이벤트 3~8개 선정
5. 차트 명세 JSON 생성 (ChartGenerator 전달용)
6. 요약 문단 작성 (섹션 메시지 최종 정리)

## 필수 요소
- [ ] 비교 매트릭스 1개
- [ ] 타임라인 1개 (프로젝트 2개 이상인 경우)
- [ ] 차트 1개 이상
- [ ] 섹션 요약 (section-summary 컴포넌트)

## 출력 형식
HTML fragment. 순서대로 매트릭스 → 타임라인 → 차트 placeholder → 요약. 각 구성 요소 앞에 짧은 도입 문단(1~2문장).
