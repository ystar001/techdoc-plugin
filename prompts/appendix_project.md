## 11블록 구조 (30,000자 기준)

### ① 프로젝트 연대기 (2,000~2,500자)
- 시작 배경 (과거 연구·정책 맥락)
- 분기점·결정적 사건
- 연도별 전환점 (10~20개 이벤트)
- 현재까지의 궤적

### ② 연구 체계 (1,500~2,000자 + 조직도)
- 핵심 연구자 커리어·직책
- 역할 분담 구조
- 외부 자문·국제 협력
- 자금원 연대기

### ③ 단계별 기술 접근 (5,000~6,000자)
- Phase 1 (초기): 방법론·가설·중간 결과
- Phase 2 (중기): 접근 전환·핵심 돌파
- Phase 3 (후기): 확장·응용·검증
- 각 Phase별 문서화 (논문·보고서)

### ④ 실험 설계 상세 (4,500~5,500자)
- 실험 설계 프레임워크
- 장비 스펙 (제조사·모델·정확도)
- 독립·종속·통제 변수 각각
- 측정 프로토콜 (반복·재현 조건)
- 재현성 평가 결과

### ⑤ 데이터셋·리소스 (1,500~2,000자)
- 수집 데이터 규모·형식
- 공개 여부·접근 조건·라이선스
- 버전 관리·업데이트 정책
- 파생 데이터셋·벤치마크

### ⑥ 핵심 결과 심층 (5,500~6,500자, 핵심)
- 주요 지표 수치의 **의미** 해석
- 통계적 유의성 (p-value, 신뢰구간)
- 다른 연구와 비교
- 예상 외 발견 (서프라이즈)
- 한계·반증 가능성
- 재현 시도 결과

### ⑦ 파생·후속 연구 (2,500~3,000자)
- 직접 인용 10+편 논문 분석
- 파생 프로젝트 지도 (누가 이어받았는가)
- 기술 이전 (산업 이전 사례)
- 표준 기여

### ⑧ 경쟁·보완 프로젝트 비교 (2,500~3,000자)
- 유사 프로젝트 7~10개
- 8개 축 비교 매트릭스
- 포지셔닝 (경쟁 vs 보완)
- 글로벌 R&D 지형 내 위치

### ⑨ 상업화·산업 응용 (1,500~2,000자)
- 스타트업 스핀오프 목록
- 라이선스·파트너십
- 표준화 기여
- 시장 침투 수치

### ⑩ 핵심 연구자 프로필 (1,500~2,000자)
- PI 커리어 (학위·소속·직책·대표 논문)
- 주요 저자 3~5명 프로필
- 학계 영향력 지표 (h-index, 인용)
- 공동 연구 네트워크

### ⑪ 전문 참고문헌 (25~40건)
- 원 논문 + cited-by 영향력 있는 후속
- 각 REF 3~5줄 주석
