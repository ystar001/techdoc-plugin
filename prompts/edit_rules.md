# 교정·편집 규칙 (Editor, Step 7)

메인 Claude 세션이 섹션 작성 후 수행하는 **문장 수준 교정**.

## 교정 범위 (5가지)

### 1. 맞춤법·띄어쓰기
- 한국어 맞춤법 표준 준수
- 외래어 표기법 (예: "알고리즘" ✓, "알고리듬" ✗)
- 합성어·복합어 띄어쓰기 (예: "스마트농업" 한 단어)

### 2. 주어-서술어 호응
- 주어 생략 자제 (기술 서술은 주어 명시 우선)
- 능동태 선호
- 수식어 위치 (꾸미는 대상 앞)

### 3. 번역체 → 자연스러운 한국어
- "~에 있어서" → "~에서", "~의 경우"
- "~함에 있어" → "~할 때"
- "가지고 있다" → "있다"
- "~되어지다" → "~되다"
- "it is ... that" 구문 → 능동 재배치

### 4. 중복 표현 제거
- 역전 앞 두루마리 (불필요 중복)
- 같은 단락 내 같은 어미 3회 이상 → 변형
- 동의어 반복 → 정리

### 5. 서술 형식 일관성
- 서술형 ↔ 개조식 혼재 금지
- 문단 단위로 스타일 통일

## 용어 통일 (glossary 기반)
- `outline.glossary`에 정의된 표준 용어 강제
- 불일치 단어 자동 교체
- 영문 약어 첫 등장 시 풀이 병기

## 인용 형식 통일
- [REF-xxx] 문장 끝 배치 (REQ-010)
- 각주 인덱스는 `<sup>` 태그 유지
- 참고문헌 번호 순서 확인

## 표·그림 번호 일관성
- `[그림 1.2]`, `[표 3.1]` 형식
- 본문 참조와 캡션 번호 일치

## 편집하지 말아야 할 것
- **수치** (원문 보존)
- **고유명사** (기관명·제품명·프로젝트명)
- **[REF-xxx]** 인용 ID
- **메타 데이터** (프로젝트 기간·예산)

## 효율적 호출
- 짧은 섹션 3~5개 묶어서 1회 처리
- 긴 섹션·별첨은 개별 처리
- 카드 단위 재작성 후 필수 교정 1회

## 출력 형식
문단별 교정 적용 후 HTML fragment 반환. 변경 요약도 함께:
```json
{
  "section_id": "1.1",
  "edited_html": "<section>...",
  "corrections": 12,
  "categories": {
    "맞춤법": 3,
    "번역체": 4,
    "용어통일": 2,
    "중복표현": 3
  }
}
```

## 과편집 금지
- 저자 의도 변형 금지
- 기술 용어 "친숙한 표현"으로 대체 금지 (예: "알고리즘" → "방법" ✗)
- 길이 단축을 위한 핵심 정보 삭제 금지
