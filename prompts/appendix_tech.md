# 기술 심층분석 별첨 작성 템플릿 (10블록, v1.5 — 2배 확대)

문서 말미 Appendix. 선정된 **high-importance 기술 카드**를 상세 리뷰 논문 수준으로 해부.

## 분량 기준 (v1.5 확대)
- **최소**: 15,000자 (15페이지)
- **권장**: 20,000~25,000자 (20~25페이지)
- **상한**: 40,000자 (35페이지)

## 10블록 구조 (25,000자 기준)

### ① 기술 개요·연구사 (1,500~2,000자)
- 등장 배경·해결 문제
- 기술 계보 (전신 기술·영향 관계)
- 주요 마일스톤 연표 (5~10개)
- 역사적 맥락·학파

### ② 수학·물리 원리 (3,000~4,000자)
- 이론적 기초 (관련 정리·법칙)
- 핵심 수식 유도 (MathJax LaTeX)
- 근사·가정의 타당성 논의
- 관련 정리 증명 개요 (필요 시)

### ③ 상세 알고리즘·프로토콜 (5,000~6,500자, 핵심)
- 알고리즘 3~5개 독립 서술
  - 각 알고리즘: 의사코드 (pseudocode 태그 사용)
  - 시간·공간 복잡도
  - 최적화 기법
  - 변형·확장
- 시퀀스·상태 다이어그램 (Mermaid)

### ④ 구현 아키텍처 (2,500~3,000자)
- HW/SW 스택 레이어별 상세
- 데이터 흐름도 (Mermaid)
- 상태 머신
- 컴포넌트 다이어그램 (C4 또는 custom)

### ⑤ 성능 벤치마크 (3,000~4,000자)
- 10개 이상 지표 × 10개 이상 비교 대상
- 실험 조건 해설 (하드웨어·데이터셋·파라미터)
- 결과 해석 (왜 이런 차이가 나는가)
- 레이더 차트·막대 차트 (ChartGenerator)

### ⑥ 주요 구현체·오픈소스 (1,500~2,000자)
- 5개 이상 구현체 비교
- 코드 예시 (최소 1~2개)
- 라이선스·커뮤니티 활성도
- 프로덕션 사용 사례

### ⑦ 연구 동향 타임라인 (1,500~2,000자)
- 20년 역사 개관
- 결정적 논문·기업 진입·특허 흐름
- 연도별 주요 이벤트 (15~25개)
- 타임라인 차트 (ChartGenerator)

### ⑧ 한계·미해결 과제 (2,500~3,000자)
- **이론적 한계**: 알고리즘·복잡도 상한
- **실용적 한계**: 현장 배포의 어려움
- **윤리적 한계**: 프라이버시·공정성
- **경제적 한계**: 비용·인프라
- 각 한계별 구체 실패 사례 또는 시나리오

### ⑨ 미래 연구 방향 (1,500~2,000자)
- 5~10년 로드맵
- 유망 연구 가설
- 타 기술과의 융합 가능성
- 촉매 요인 (새 하드웨어·데이터셋·규제)

### ⑩ 전문 참고문헌 (20~30건)
- 심화 학습용 (본문 REF와 중복 허용)
- 각 REF에 3~5줄 주석 (해당 자료가 왜 중요한지)

## 시각화 필수
- **MathJax 수식**: 블록 ②③⑤
- **Mermaid 다이어그램**: 블록 ③④ (시퀀스·상태·컴포넌트)
- **matplotlib 차트**: 블록 ⑤⑦ (벤치마크·타임라인)

## 자체 검증
- [ ] 10블록 모두 채움
- [ ] 총 분량 ≥ 15,000자
- [ ] 알고리즘 3~5개 독립 서술
- [ ] 수식·다이어그램·차트 최소 각 1개
- [ ] [REF-xxx] 인용 20건 이상

JSON with `id`, `source_card_id`, `name`, `name_en`, + 10 block keys (overview, theory, algorithms, architecture, benchmark, implementations, timeline, limitations, future, references), `ref_ids`, `equations` (list of MathJax fragments), `diagrams` (list of Mermaid specs).
