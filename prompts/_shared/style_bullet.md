# 개조식 문체 (공문서 스타일)

## 기조
공문서처럼 짧고 명확하게. 항목화, 명사형 종결, 표·목록 중심.

## 문장 규칙
- 명사형 종결: `~임`, `~함`, `~필요`, `~예정`, `~중`
- 핵심 정보만 1~2줄로 압축
- 불필요한 수식어·접속사 배제
- 완전한 문장보다는 구(句) 단위 허용

## 항목화 원칙
- 같은 계층은 같은 형식으로 통일
- 들여쓰기로 계층 표현 (최대 3단계)
- 중요 수치는 별도 하이라이트 가능

## 예시
### 개조식 (권장)
```
○ 기술 성능
  - 정확도 94.3% (기존 81% 대비 +13%p)
  - 소비전력 0.8W (업계 평균 2.1W)
  - 도입 규모 500노드, 12km² 농지
○ 주요 성과
  - 물 사용량 32% 절감
  - 운영비 연 2,400만원 감소
```

### 서술형 (개조식 아님)
```
~기술은 정확도 94.3%를 달성했으며, 이는 기존 81% 대비 13%p 향상된 수치이다...
```

## 금지
- 완전한 서술형 문장 남용
- 감정적 표현
- 1인칭·2인칭
