# 7종 분석 방법론 태그

섹션·카드의 분석 태그는 해당 내용이 어떤 방식으로 독자에게 전달되어야 하는지를 지정한다.

## 우선순위 매칭 (섹션 제목·하위 항목 키워드 기반)

| 우선순위 | 키워드 | 태그 | 서술 역할 |
|---|---|---|---|
| 1 | 개요·정의·핵심 원리·원리 | `[분석: 개념정의]` | "무엇인가"를 먼저 정의 |
| 2 | 구조·시스템·아키텍처·구성 | `[분석: 구조분석]` | "어떻게 구성되는가" |
| 3 | 현황·동향·추이·시장 | `[분석: 현황분석]` | "지금 어떤 상태인가" |
| 4 | 비교·차이·대비·vs | `[분석: 비교분석]` | "무엇이 다른가" |
| 5 | 사례·적용·도입·실증 | `[분석: 사례분석]` | "실제로 어떻게 쓰이는가" |
| 6 | 도전·과제·한계·문제 | `[분석: SWOT]` | "무엇이 문제인가" |
| 7 | 전망·미래·로드맵·향후 | `[분석: 시나리오]` | "앞으로 어떻게 되는가" |

## 기본 태그
매칭 키워드 없음 시: `[분석: 인과관계]`

## 태그별 필수 요소

### [분석: 개념정의]
- 대상의 정의·범주·핵심 속성
- 유사 개념과의 경계
- 역사적 등장 맥락 (간략)

### [분석: 구조분석]
- 구성 요소 목록 (HW/SW 분리)
- 요소 간 상호작용
- 데이터·전력·신호 흐름

### [분석: 현황분석]
- 정량 지표 (시장 규모·채택률·성장률)
- 지역·산업별 분포
- 최근 3~5년 추세

### [분석: 비교분석]
- 비교 매트릭스 (5~7개 축 × N개 대상)
- 각 축에서의 우위·열위
- 선택 가이드

### [분석: 사례분석]
- 구체 사례 (기관·기간·규모)
- 적용 방법
- 정량 성과 (전후 비교)

### [분석: SWOT]
- Strengths·Weaknesses·Opportunities·Threats
- 각 항목 근거 제시

### [분석: 시나리오]
- 낙관·기본·비관 3시나리오
- 각 시나리오 가정·결과
- 변곡점·촉매 요인
