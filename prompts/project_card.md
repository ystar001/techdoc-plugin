# 프로젝트 카드 작성 템플릿 (7블록)

본문 섹션 내 독립 카드. 특정 연구 프로젝트·R&D 이니셔티브 하나를 개괄.

## 분량 기준 (중요도별)
- **high**: 3,000~4,000자
- **medium**: 2,000~3,000자 (기본)
- **low**: 1,200~2,000자

상한: 4,000자. 박사논문 수준 심층 내용은 **별첨**으로.

## 메타 헤더 (블록 앞 표시)
| 항목 | 내용 |
|---|---|
| 수행 기관 | 주관·공동·협력 |
| PI | 책임자 이름·소속 |
| 기간 | 시작월-종료월 |
| 예산 | 통화·금액 |
| 자금원 | 정부 부처·민간 기업 등 |

## 7블록 구조

### ① 프로젝트 배경·목적 (400자)
- 왜 시작했는가 (문제의식·기회)
- 상위 정책·프로그램과의 연결
- 프로젝트가 달성하려는 구체 목표

### ② 수행 체계 (300자 + 표)
- 조직도 (주관기관-공동기관-협력기관)
- 핵심 인력 역할
- 외부 자문단·국제 협력 (있는 경우)

### ③ 연구 방법론 (700~900자)
- 실험 설계 개요 (대조군·실험군·변수)
- 사용 장비·플랫폼
- 데이터 수집 프로토콜
- 분석 기법 (통계·ML·시뮬레이션)

### ④ 핵심 결과 (700~900자, 정량)
- 주요 지표별 수치 (정확도·효율·비용·성과)
- 가설 검증 결과 (지지 여부)
- 예상 외 발견
- 시각화 (그래프·차트)

### ⑤ 시사점·기술 기여 (400자)
- 해당 분야에 미치는 영향
- 학술적 기여 (논문·특허)
- 산업적 응용 가능성

### ⑥ 후속 연구·파급 효과 (300자)
- 이어지는 연구 프로젝트
- 타 그룹이 인용·응용한 사례
- 표준화·상용화 진행 상황

### ⑦ 근거·인용 (200자)
- 3~5건 [REF-xxx] 핵심 논문·보고서
- 각 REF의 핵심 기여 요약

## 자체 검증
- [ ] 메타 헤더 5개 항목 모두 채움 (없으면 `-` 표기)
- [ ] 정량 수치 최소 5건 이상
- [ ] [REF-xxx] 인용 5건 이상
- [ ] 최소 분량 충족

## 출력 형식
JSON with keys: `id`, `name`, `name_en`, `importance`, `institution`, `pi`, `period`, `budget`, `sponsor`, + 7 block keys (`background`, `organization`, `methodology`, `results`, `implications`, `followup`, `references`), `ref_ids`.
